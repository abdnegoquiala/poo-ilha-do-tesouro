## Descrição

Ilha do Tesouro é um jogo de tabuleiro em Java
para 2 a 4 jogadores.

O objetivo é chegar exatamente à casa 30.

O jogo inclui turnos, lançamento de dado e
movimentação dos jogadores.

## Estado do projeto — Outubro

O protótipo inicial permite:

- Apresentar um tabuleiro gráfico com 30 casas.
- Movimentar três jogadores de demonstração.
- Lançar um dado aleatório de 1 a 6.
- Alternar entre jogadores.
- Validar movimentos e detetar a vitória.

As restantes funcionalidades serão
implementadas nas próximas etapas.

## Execução

1. Abrir o projeto no IntelliJ IDEA.
2. Configurar um JDK compatível.
3. Executar `src/jogo/Main.java`.
4. Utilizar o botão "Lançar dado" para jogar.
